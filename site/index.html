A small bar for a remote service

Enter http://localhost:1331 for the selected machine and choose Go. Save the connection to reopen it in one click. Advanced controls reveal the SSH direction and port settings; live connections have a Stop action.

Take your setup with you

Import or export your machines and preferences. Passwords, private keys and clipboard contents stay out. Review network addresses before sharing an export.

A moment to change your mind

Clear the shelf, then Undo within ten seconds. Ordinary source files stay where they were. Sending creates a new destination folder rather than replacing existing files.

Installing the app onto another machine is currently a Mac-only flow. Normal SSH transfers are separate.

A few things to know.

Does the other machine need ShelfDock?

Not for ordinary transfers. It needs a reachable, already trusted SSH server, an account with access, and the supported transfer tools. ShelfDock can use your existing keys or help set up a dedicated key through a one-time password. It cannot enable an unreachable SSH server for you.

Does it watch my clipboard?

Clipboard tools start disabled. Enabling them does not enable automatic history; that is a separate choice. You can still explicitly paste into the Transfers shelf. If you enable history, pause it before copying secrets because some applications do not mark sensitive clipboard content.

Can I send to more than one machine?

Yes. Select the shelf items and target machines, review the recipients, then send. Results are tracked separately for each destination. A direct drop still sends only to the machine you dropped onto.

Will a transfer replace my files?

Each send gets a new folder inside the destination you choose, usually Desktop. Original files stay on the sending machine. A failed transfer can leave partial files in its new folder; a retry uses a fresh folder.

Is this an open-source or production release?

This is a preview. The repository is available for reviewing the project, but a distribution license has not been chosen; do not assume an open-source license. Packages are currently unsigned and platform testing is incomplete. Read the release notes before installing.

Does the website upload anything?

No. The interactive shelf uses fictional data and simulates its actions locally in your browser. It does not read your clipboard, accept real file uploads or contact your machines. This page includes no analytics or third-party fonts.
